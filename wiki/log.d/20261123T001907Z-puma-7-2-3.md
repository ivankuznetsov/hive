# Bump puma to 7.2.3 in the web bundle

- `bundler-audit` failed on main: `web/Gemfile.lock` pinned puma 7.2.2, which
  has advisory GHSA-4v6q-hvv7-49h9, fixed in 7.2.3.
- The lockfile now pins puma 7.2.3, the patch release. A plain
  `bundle lock --update puma` would jump to 8.1.2, a major version, which
  this fix does not need.
