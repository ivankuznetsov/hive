# Hive 0.8.0 technical changelog

Compare: [v0.7.4…v0.8.0](https://github.com/ivankuznetsov/hive/compare/v0.7.4...v0.8.0).

Source range: `v0.7.4` through `7049af068bc8e14ea1dc8ad63865e2d36b0029b7` (74 first-parent merges), followed by the 0.8.0 release-preparation changes described below. PR titles are summarized by subsystem; see each PR for the full change.

## Claude launch and agent configuration

- [#1529](https://github.com/ivankuznetsov/hive/pull/1529): Claude runs headless-only; the tmux launch mode and `claude.mode` are removed.
- [#1538](https://github.com/ivankuznetsov/hive/pull/1538): agents get only Hive-granted MCP servers.
- Earlier tmux-mode fixes in this range, superseded by #1529: [#1472](https://github.com/ivankuznetsov/hive/pull/1472) (keep working panes busy, honor per-stage model pins), [#1475](https://github.com/ivankuznetsov/hive/pull/1475) (newer folder-trust prompt), [#1496](https://github.com/ivankuznetsov/hive/pull/1496) (bracketed prompt paste), [#1500](https://github.com/ivankuznetsov/hive/pull/1500) (deny AskUserQuestion), [#1501](https://github.com/ivankuznetsov/hive/pull/1501) (fail fast on a stranded menu).
- [#1473](https://github.com/ivankuznetsov/hive/pull/1473): Codex plan-model walls are treated as limits and honored in open-PR.
- [#1485](https://github.com/ivankuznetsov/hive/pull/1485): Codex retry notices no longer mask the terminal provider error.
- [#1546](https://github.com/ivankuznetsov/hive/pull/1546): a provider-refused model stops the task instead of being retried as a limit.
