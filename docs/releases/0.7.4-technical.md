# Hive 0.7.4 technical changelog

Compare: [v0.7.3…v0.7.4](https://github.com/ivankuznetsov/hive/compare/v0.7.3...v0.7.4).

## Daily digest

- [#1449](https://github.com/ivankuznetsov/hive/pull/1449): replaced workflow-event digest generation with a persisted Markdown document based on registered repositories' merged PR evidence. PRDigest 0.4.0 supplies descriptions, bounded relevant patches, and writing instructions. Hive invokes its configured agent and owns scheduling, persistence, CLI/Web reads and Telegram delivery. Generation defaults on; explicit disablement is respected and Telegram remains opt-in. Closed records and previous documents survive refreshes and generation failures. Provider execution is bounded and output is redacted and checked for completeness.
- [#1451](https://github.com/ivankuznetsov/hive/pull/1451): widened and compacted the Web article, removed its duplicate title/date, reduced theme headings and linked project sections to GitHub. Persisted repository statistics expose merged PRs, commits within those PRs, and additions/deletions. Existing closed documents receive metadata amendments without rewriting the base. Web additions are green and deletions red using theme colors.

## Completed workflows

- [#1452](https://github.com/ivankuznetsov/hive/pull/1452): added a Done board for completed workflow tasks and preserved filtering and task navigation.

## Packaging and release verification

- [#1448](https://github.com/ivankuznetsov/hive/pull/1448): recovered distribution publication and verification for 0.7.3.
- [#1450](https://github.com/ivankuznetsov/hive/pull/1450): made component release smoke use the pinned OpenCode launcher and explicit offline route.
- Release preparation synchronizes version, both locks, installer URLs and generated agent-skill projection; advances the authenticated latest-stable baseline to 0.7.3.

## Data and API notes

Documents remain separate from legacy workflow-event digest state. The CLI JSON digest envelope has optional `repository_stats`; Markdown text stays portable to CLI and Telegram. LOC changed is additions plus deletions, and these totals do not count direct commits outside merged PRs. Read-only Web requests do not collect evidence or invoke an agent.
