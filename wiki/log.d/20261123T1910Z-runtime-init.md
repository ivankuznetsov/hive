- 2026-11-23: `hive runtime init` is a service-free runtime bootstrap: it creates the runtime database when missing and records every registered project in it, without services, agent skills, bundles or enrollment ([[commands/runtime]], [[cli]]). `hive setup`'s runtime phase now syncs registered projects too, so a project enrolled before the database existed can dispatch attempts. Found by hivedev's F4 hosting proof: in a workspace container, `hive run` failed with "runtime control-plane database is missing; run hive setup", and after a manual bootstrap with "attempt project identity is not registered for the task path".
