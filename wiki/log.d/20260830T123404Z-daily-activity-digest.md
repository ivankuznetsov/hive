# Add Hive-owned daily activity history

Hive now persists one host-global daily activity projection across registered
projects. Explicit IANA-zone intervals keep historical boundaries stable; open
records refresh atomically, closed bases remain immutable, and late facts or
source recovery appear as audited amendments. Material task/PR outcomes,
boundary attention, scoped source gaps, and project-membership history share
one collector and durable frontier protocol.

The same pure reader now supplies concise `hive digest` text, a stable JSON
agent contract, and an authenticated attention-first Rails day view. Explicit
refresh, projection-only prune, and Telegram send actions remain separate from
reads. Daemon refresh/close and opt-in recap delivery use independent scheduler
and capacity identities; complete empty days suppress delivery, and ambiguous
sends require an explicit operator retry.

The canonical Hive skill routes today/yesterday/project-history questions to
`hive digest --json`, follows persisted interval navigation, and forbids status
or log reconstruction, implicit refresh, Telegram delivery, machine-mode Web
opening, and the unrelated sendful answer digest. The generated OpenClaw
projection remains byte-identical to that canonical source.
