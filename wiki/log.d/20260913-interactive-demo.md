## 2026-09-13 — Static Hive demo and Cloud waitlist

Added `demo/`, an independently deployable public explorer generated from actual
Hive Web templates with fictional task fixtures. Browser-local controls advance
two prepared dark-mode stories without agent execution. The optional waitlist
uses a dedicated Worker/D1 endpoint and server-verified Turnstile; local builds
leave collection disabled. Added export-boundary, D1 failure/duplicate, and
desktop/mobile browser checks. See [[interactive-demo]]. Public deployment and
production configuration are not performed by the build.
