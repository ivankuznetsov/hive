---
title: Make long Markdown artifacts easier to read
type: change
date: 2026-08-14
---

Hive Web now presents rendered task Markdown as a long-form document: full-size
body text, generous leading, clearer heading hierarchy, stronger section rhythm,
and a centered 82-character prose measure. Direct fenced code and tables can use
the wider document panel on desktop, then scroll inside it at narrow widths
instead of widening the task page. A browser regression pins the desktop
typography and evidence width plus the mobile overflow contract.
