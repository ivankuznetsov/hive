---
title: Harden task workspace evidence boundaries
date: 2026-08-13
---

The task workspace now validates and redacts typed context-receipt assertions,
protects controller receipts during agent custody, verifies the complete
checkpoint prefix, and treats absent usage and degraded action evidence as
unknown rather than current.

Timeline pagination can seek bounded source windows older than the newest
suffix, dependency publication facts are collected per connected node, and
cycle analysis runs only after bounded selection. GitHub refreshes have a total
deadline and honor server cooldowns, while legacy status contexts preserve
pending and failure meaning.

The v1 workspace schema now closes and types panel records. Task-scoped Turbo
frame identities, concise diff announcements, path-scrubbed Git diagnostics,
and a valid question anchor keep authenticated HTML and JSON aligned with those
evidence boundaries.
