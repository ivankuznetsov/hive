- Added one bounded, schema-validated project projection for ordinary and
  Architecture discovery, admission, workflow stages, migration, successors,
  publication, post-merge work, and telemetry-only current-day token usage.
- Composed source authorities once in the existing daemon and passed the same
  projection through Status, Watch, TUI, bot, and web. Source failures are
  isolated and malformed consumer extensions fail closed to a bounded
  unavailable row.
- Counted conversion cohorts by unique mechanical roots, separated created and
  open PRs, and reported only latency with durable timing authority. Scheduled
  discovery allowances remain independent of workflow concurrency and token
  observations never become budgets.
- Retired active Architecture issue creation, its reachable writer/capability
  paths, and fresh-install permission while retaining read-only legacy issue
  provenance for migration. Patrol findings now route through internal tasks
  before fixes and PR publication.
- Recorded the bounded-candidate, unreadable-neighbour, insufficient semantic
  evidence, and synchronous provider-custody release blockers for U11 rather
  than adding another coordinator or daemon.
