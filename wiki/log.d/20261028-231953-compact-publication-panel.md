# Compact Code changes panel and document section label

The task Code changes panel keeps title and state in one row, puts the PR and View diff links side by side, drops the Pull request / Pull request status subheadings and shows GitHub's observation as one muted line that names the remote state only when it differs from the badge. Checks, description, Git details and diagnostics are preserved. The primary document's Plan/Implementation/Review label is a contrast-checked amber sans label (`.document-section-label`), distinct from the document title. See [[commands/web]].
