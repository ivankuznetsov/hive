# `hive new PROJECT text --help` prints usage instead of capturing a task

- Thor shows a command's help only when the flag comes directly after the
  command name. `hive new hivedev probe --help` therefore captured a task whose
  idea text was "probe --help" (hivedev `probe-help-261119-f0b6`). Its
  brainstorm agent asked whether `hive new` should treat help flags as a
  request for usage.
- `hive new` now treats a standalone `-h` or `--help` token anywhere after
  the project as a help request: it prints the command's usage, exits 0 and
  creates nothing.
- Other dashed tokens stay task text, for example `--help-text` or a flag
  named in an idea. Thor never rejected unknown options for this command, and
  it still doesn't.
