---
title: Make long Markdown artifacts easier to read
type: change
date: 2026-08-14
---

Hive Web now presents rendered task Markdown as a long-form document: full-size
body text, generous leading, clearer heading hierarchy, stronger section rhythm,
and a centered 82-character reading measure. Wide fenced code and tables scroll
inside the document panel at narrow widths instead of widening the task page.
A browser regression pins the desktop typography and mobile overflow contract.
