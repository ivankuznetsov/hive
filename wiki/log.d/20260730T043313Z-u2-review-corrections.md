title: Close U2 whole-install, recovery, and root-channel review blockers
type: change
created: 2026-07-30
tags: [patrol, migration, all-users, recovery, security, packaging]
---

- Made the hourly root sweep re-enter every discovered OS-user profile and
  delegate unchanged-work admission to the user-owned live registry receipt.
  The real multi-UID gate now migrates two initial projects for each of three
  inactive users, registers a third project later under another user, and
  proves the next resume discovers and migrates it with that user's ownership.
- Replaced the isolated catalog's object deserialization pipe with a bounded,
  versioned, exact-key JSON wire. Cross-profile nested roots and unrelated-UID
  ancestor custody fail closed, and nested project retry state must agree with
  the root checkpoint before it is accepted.
- Required an already admitted ordinary Patrol capture and live configured
  effect gateway at `PrOpener`; removed the legacy allow-all construction
  fallback. One stable cycle lock now serializes predecessor recovery,
  fingerprint reads, agent work, dispatch, and settlement, while the
  fingerprint lock recovers an uncertain predecessor before preparing a
  successor.
- Preserved the root wrapper's `HIVE_INVOKED_BIN` identity so the installed
  root and AUR launchers match their immutable runtime manifests. Root installer
  preflight now uses Bash-3-compatible variable detection and portable
  canonicalization instead of GNU `readlink -f`.
- Secret-redacted, UTF-8-bounded recovery and project-migration diagnostics
  now reach occurrence state, scheduler events, user receipts, root
  checkpoints, and logs. Privileged child ingress rejects unredacted or
  contradictory project rows.
