# Native control-panel parity

Navigation says Projects and Integrations (`/projects`, `/integrations`
aliases; `/repos`, `/telegram` and their forms unchanged). Integrations
groups the real Telegram setup under a Telegram section and lists Slack as
Planned. Finished tasks lead with the single Code changes panel; active tasks
show it after the current document and before Documents. Activity-only
digests open with a summary counted from recorded rows, with record metadata
in a disclosure. Agents shows product names and workflow roles from the
selected project's config or labelled `hive init` defaults.
