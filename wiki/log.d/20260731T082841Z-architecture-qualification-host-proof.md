title: Extend Patrol host qualification to Architecture Patrol
type: change
date: 2026-07-31
tags: [patrol, architecture-patrol, qualification, recovery, security]

- Routed Architecture Patrol clean and positive controls through the private
  candidate command, production intake/scheduler, v3 JobStore, deterministic
  event publisher, detached module dispatcher, Attempts, and shadow comparator.
- Generalized the mandatory host evidence collector across both Patrol products.
  Architecture proof now binds the derived v2 manifest, v3 aggregate, every
  aggregate transition intent and receipt, action outcomes, repository HEAD,
  complete event envelope, and exact retired occurrence generation.
- Kept both candidate lanes networkless and candidate-secretless. The installed
  descriptor now names only the OpenRouter credential needed by a future
  host-owned broker; provider unavailability remains a retryable diagnostic.
- Process-generation fault custody, the provider broker and exact installed
  target, and protected-main catalog/controller proof remain open. This change
  does not authorize mutator cutover.
