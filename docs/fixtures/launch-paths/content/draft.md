# The handoff that survived a laptop restart

> **Deterministic replay fixture.** This draft is synthetic and has not been
> produced or approved by a live provider.

The laptop closed halfway through the job. The chat disappeared, but the work
did not. The brief, source notes, outline, and current workflow marker were
still ordinary files in the task folder.

That changes the handoff. A new agent does not need a perfect recap from the
previous one; it can inspect what was accepted, what artifact exists, and what
Hive says should happen next. The folder is both the durable record and the
resume point.

There is a boundary: local state cannot restore a provider outage. It can show
the hold without losing the work, then let the same stage resume when the
provider is available again.
