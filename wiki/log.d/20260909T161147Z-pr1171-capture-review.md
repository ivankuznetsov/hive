# Repair capture contracts during PR #1171 review

- Real-socket regression: a POST body sent after its headers reached `main`,
  but the PR proxy returned HTTP 400 after waiting for an upstream response
  before forwarding that body. One duplex relay now buffers only bounded
  response headers for redirect rewriting and keeps request bodies moving.
- A harmless external-file fixture proved that overlay seeding followed
  immediate runtime child symlinks. Copying now preserves those links instead
  of materializing their host targets before sandbox entry.
- Pi advertises its registered evidence server tool and grants it 100 seconds,
  exceeding the existing 95-second gateway and 90-second readiness budgets.
- Review guardrails reuse the exact waiver parser also used by CleanExit.
  Removed unused password regex constants, a redundant evidence-producer
  wrapper, a test-only resolver alias, and redundant candidate acceptance logic.
- Regression coverage includes split POST bodies, bounded/split response
  headers, external-target symlinks, and generated Pi tool contracts. Timer
  cancellation checks thread termination instead of a 50 ms scheduling race.
