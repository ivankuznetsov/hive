# migrate-every-agent-plugin-to-260709-3082

Migrate every agent plugin to portable skills across Claude Code, Codex, Pi, and OpenClaw. First, update the Screenote plugin's screenote, snapshot, and feedback skills to stop using the Screenote MCP server and instead invoke the merged OAuth-first Screenote CLI from screenote PR #37. Use the machine-readable JSON command contract: screenote project list, page list, screenshot list/create, annotation list/get, and comment add; authenticate via screenote login or SCREENOTE_TOKEN/config token; select projects through --project, SCREENOTE_PROJECT, or config; preserve safe capture/upload behavior and actionable missing_token, invalid_token, and missing_project handling. Remove obsolete .mcp.json wiring once no skill depends on it, without retaining a hidden MCP fallback. Then audit all plugins in ivankuznetsov/agent-plugins and provide first-class skill packaging for all supported agents: retain Claude and Codex surfaces, add Pi skill manifests/invocations where absent, and add OpenClaw SKILL.md-compatible packages for every plugin. Keep one canonical instruction source per skill where practical and generate or validate agent-specific adapters to prevent drift. Update marketplace metadata, installation documentation, structural lint/evals, and CI. Acceptance: every marketplace plugin has an explicit Claude, Codex, Pi, and OpenClaw install/use path; Screenote skills exercise the CLI rather than MCP; auth tokens are never printed; noninteractive CI works with SCREENOTE_TOKEN and project selection; manifests and referenced skill files validate; tests catch missing or divergent platform adapters.
