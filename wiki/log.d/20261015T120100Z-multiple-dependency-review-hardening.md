# Harden multiple-dependency diagnostics and observation paths

Cycle-derived admission evaluations now carry their active cycle anchors and
are reused only while those anchors remain on the current traversal route.
Malformed dependency evidence has one JSON-oriented display renderer, scalar
invalid metadata remains snapshot-serializable, and admission fingerprints
retain task and verdict identity for corrupt declarations.

Status and durable-attempt projections share the scalar branch-inventory
policy. Successful empty inventories remain distinct from transient Git
inventory failures, which skip the evidence check instead of rewriting a
stacked base mode to `default`. Dependency workspace edge expansion now checks
both its deadline and edge budget inside wide declarations, and invalid
placeholder identity remains per source task.
